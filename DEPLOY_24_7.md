## 📋 **Инструкция развертывания на Railway:**

### 🚀 **Способ 1: Автоматическое развертывание**

1. **Подготовка:**
   - Создайте аккаунт на [Railway.app](https://railway.app)
   - Войдите через GitHub (бесплатно)
   - Получите Railway Token в настройках профиля

2. **Настройка GitHub Secrets:**
   ```
   В репозитории > Settings > Secrets and variables > Actions > New repository secret
   Имя: RAILWAY_TOKEN
   Значение: ваш_railway_token
   ```

3. **Развертывание:**
   - Сделайте push изменений в репозиторий
   - GitHub Actions автоматически развернет бот на Railway
   - Через 2-3 минуты бот будет работать 24/7

### 🔧 **Способ 2: Ручное развертывание**

1. **Создание проекта:**
   - Зайдите в [Railway Dashboard](https://railway.app/dashboard)
   - Нажмите "New Project" → "Deploy from GitHub repo"
   - Выберите репозиторий `vpn-checker-script`

2. **Настройка окружения:**
   ```bash
   В настройках проекта > Variables > Add:
   
   TELEGRAM_BOT_TOKEN=your_bot_token_from_BotFather
   WEBHOOK_URL=https://your-app-name.railway.app/webhook
   PORT=8080
   ```

3. **Запуск:**
   - Railway автоматически определит Python приложение
   - Сервис запустится и будет работать 24/7
   - Ваш бот будет доступен всегда!

## 🔑 **Получение TELEGRAM_BOT_TOKEN:**

1. **Создайте бота:**
   - Найдите [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте: `/newbot`
   - Введите имя бота: `VPN Checker Bot`
   - Введите username: `vpn_checker_bot` (уникальный)

2. **Получите токен:**
   - BotFather пришлет токен вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
   - Скопируйте этот токен

## 🔗 **Настройка Webhook URL:**

После развертывания на Railway:

1. **Получите URL приложения:**
   - Railway Dashboard → Ваш проект → Settings → Domains
   - Скопируйте URL вида: `https://your-app-name.railway.app`

2. **Установите webhook:**
   ```
   WEBHOOK_URL=https://your-app-name.railway.app/webhook
   ```

3. **Проверьте работу:**
   ```
   curl https://your-app-name.railway.app/
   # Ответ: {"service": "VPN Checker Bot", "mode": "webhook", ...}
   
   curl https://your-app-name.railway.app/health
   # Ответ: {"status": "healthy", "bot": "running"}
   ```

## 🚨 **Устранение проблем:**

### Проблема: Бот не отвечает
1. Проверьте TELEGRAM_BOT_TOKEN в переменных окружения
2. Убедитесь что webhook URL правильный
3. Проверьте логи в Railway Dashboard

### Проблема: Ошибка 403 webhook
1. Убедитесь что webhook URL доступен извне
2. Проверьте что PORT=8080 установлен
3. Перезапустите сервис в Railway

### Проблема: Бот падает
1. Проверьте логи ошибок в Railway
2. Убедитесь что все зависимости установлены
3. Попробуйте ручное развертывание
