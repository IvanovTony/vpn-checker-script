# 🚀 Развертывание VPN Checker Bot на Railway.app

## 📋 Инструкция по установке

### Шаг 1: Создайте Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Напишите `/newbot`
3. Следуйте инструкциям:
   - **Имя бота:** `VPN Checker Bot` (или любое другое)
   - **Юзернейм:** `vpn_checker_script_bot` (или уникальный)
4. **Скопируйте токен** - он выглядит как: `1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ`
   - ❌ Не делитесь токеном ни с кем!

### Шаг 2: Создайте аккаунт Railway

1. Зайдите на [railway.app](https://railway.app)
2. Нажмите **"Login"**
3. Войдите через GitHub (рекомендуется) или Google

### Шаг 3: Создайте проект

1. После входа нажмите **"+ New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. Найдите и выберите ваш репозиторий `vpn-checker-script`
4. Railway автоматически определит Python
5. Нажмите **"Deploy"**

### Шаг 4: Добавьте переменные окружения

1. После создания проекта зайдите в него
2. Нажмите на вкладку **"Variables"** (или "Settings" → "Variables")
3. Нажмите **"+ New Variable"**
4. Добавьте:
   ```
   Key: TELEGRAM_BOT_TOKEN
   Value: ваш_токен_от_BotFather
   ```
5. Нажмите **"Add"**

### Шаг 5: Дождитесь развертывания

1. Railway автоматически начнет развертывание
2. Это займет **1-3 минуты**
3. Вы увидите логи в вкладке **"Deployments"**
4. Когда увидите ✅ - бот готов!

### Шаг 6: Проверьте бота

1. Откройте вашего бота в Telegram
2. Напишите `/start`
3. Если бот отвечает - всё работает! 🎉

## 🐛 Решение проблем

### Проблема: Бот не отвечает

**Решения:**
1. Проверьте логи в Railway (вкладка "Deployments" → "View logs")
2. Убедитесь, что `TELEGRAM_BOT_TOKEN` добавлен в Variables
3. Проверьте, что токен правильный (без пробелов)
4. Перезапустите deployment (кнопка "Redeploy")

### Проблема: Ошибка "Module not found"

**Решение:**
1. Убедитесь, что файл `requirements.txt` существует в репозитории
2. Все зависимости должны быть там
3. Railway автоматически установит их

### Проблема: Бот останавливается

**Решение:**
1. Railway автоматически перезапустит бот при ошибке
2. Проверьте логи для понимания причины
3. Если проблема повторяется - проверьте код на ошибки

### Проблема: Нет ключей в боте

**Решение:**
1. Ключи находятся в папке `checked/`
2. Убедитесь, что папка `checked/` существует в репозитории
3. Если ключей нет - запустите `python main.py` локально для генерации

## 📝 Автоматическое обновление ключей

Railway **НЕ** автоматически запускает `main.py` для обновления ключей.

**Чтобы обновить ключи:**

### Вариант 1: GitHub Actions (РЕКОМЕНДУЕТСЯ)

У вас уже есть GitHub Workflow `.github/workflows/run_check.yml`

Он автоматически будет:
1. Проверять ключи
2. Сохранять в репозиторий
3. Railway автоматически подтянет изменения

### Вариант 2: Вручную

1. Запустите локально: `python main.py`
2. Зафиксируйте изменения: `git add . && git commit -m "Update keys"`
3. Запушьте: `git push`
4. Railway автоматически обновится

### Вариант 3: Добавить автообновление в Railway

Для этого нужно изменить `railway.py` для добавления таймера обновления (дополнительная настройка).
